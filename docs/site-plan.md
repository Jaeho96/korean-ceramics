# 흙으로 빚은 달: 한국 도자기 소개 사이트 계획

한국 전통 도자기(달항아리 · 청자 · 백자 · 분청사기 · 옹기)를 알리는 한 페이지 스크롤 사이트다. 흙 한 덩이가 그릇이 되는 과정을 따라가고, 마지막에 완성품을 모아 보여 준다. 3D 에셋은 외부 에셋 없이 코드와 Blender 로 만든다. 2026-11-19 사용자가 이 방향과 화면 흐름을 정했다.

## 화면 흐름과 진행 상태

| 장 | 화면 | 상태 |
|---|---|---|
| 첫 화면 | 정지 이미지를 먼저 띄우고 3D 가 준비되면 바꿔 낀다, 제목 뒤 달항아리 | 됨. `assets-src/poster.mjs` 가 개발 서버 `?poster` 모드의 첫 장면을 투명 배경으로 찍는다(2880x1800, 77KB) |
| 01 흙 | 점토 덩어리가 마우스에 눌리고 밀린다 | 됨. SDF 대신 메시 변형(닿은 자리는 들어가고 둘레는 밀려 나옴, 깊이 상한) |
| 02 물레 | 스크롤에 따라 단면이 자라 항아리가 솟고, 단면 점을 끌어 빚는다 | 됨. 다 솟으면 손잡이 6개, 좌우로 끌면 그 높이의 반지름이 바뀐다 |
| 03 유약 | 옹기 · 청자 · 백자 유약을 고르면 위에서부터 흘러내린다 | 됨. 셰이더에서 높이 경계 + 둘레 잡음으로 흘러내린 자국, 장에 들어오면 청자 유약을 한 번 붓는다 |
| 04 가마 | 불빛이 달아올랐다 식으며 빙렬이 생긴다 | 됨. 청자 매병(코드로 만든 단면), 스크롤로 열 0→1→0, 식는 동안 보로노이 칸 경계가 차례로 드러난다, 불티 · 불빛 |
| 05 컬렉션 | 완성품을 돌려 본다 | 됨. 달항아리 · 매병 · 옹기 · 청자 사발 · 백자 잔, 끌어서 돌린다. 분청사기 3D 는 없다 |
| 06 만든 방법 | 에셋 제작 과정과 실측 수치 | 됨. 메시 골격 달항아리, 실측 수치 3개(LCP 0.09초 · 긴 작업 합계 0.15초 · 스크롤 72fps), 출처 10곳 |

본문 사실(시대 · 기법 · 대표 유물)은 `docs/content-research.md` 에서 공식 출처로 확인한 것만 쓴다. 2026-11-19 본문을 채우면서 세 가지를 원문으로 다시 확인했다(국가유산청 국보 2007-1 기록의 시기 · 접합 · 40cm, 국가유산청 웹진의 청자 초벌 850℃ · 재벌 1,200~1,280℃, 백과사전 분청사기의 15 · 16세기 약 200년 · 귀얄 · 덤벙). 굽는 온도는 하위 조사가 같이 적은 교육영상 수치(700~900℃ / 1,200~1,300℃) 대신 직접 확인한 웹진 수치를 썼다. 미확인 15건(빙렬 원인, 타렴, 잿물 배합 등)은 본문에 넣지 않았다.

## 지금 구조

- `index.html` 사이트, `viewer.html` 에셋 확인용 뷰어(`?set=blender`).
- `src/site/main.js`: Lenis 부드러운 스크롤, GSAP ScrollTrigger 로 장마다 글자 등장. 3D 는 첫 화면이 그려진 뒤 `requestIdleCallback` 으로 `scene.js` 를 따로 불러온다. 첫 화면의 가장 큰 요소가 제목 글자가 되게 해서 LCP 를 3D 로드와 떼어 놓았다.
- `src/site/scene.js`: 고정 캔버스, 달항아리 glb(412KB), 캔버스로 그린 접지 그림자. 스크롤 타임라인이 장마다 항아리를 글자 반대편으로 옮긴다. 비키는 거리는 카메라에서 보이는 반폭에 비례하고, 세로 화면(가로/세로 < 0.8)에서는 비키지 않고 위로 올린다. CSS 도 같은 기준으로 글자를 아래로 내린다.
- 글꼴: Noto Serif KR(제목), Pretendard(본문), 둘 다 OFL, 유니코드 범위로 쪼갠 파일이라 쓰는 글자만 받는다.
- `prefers-reduced-motion` 이면 부드러운 스크롤과 회전을 끈다.

## 한국어 · 영어(2026-11-19 사용자 결정으로 추가)

- `src/site/i18n.js` 의 `STRINGS` 에 두 언어 글이 있고, HTML 은 한국어다. 영어면 `data-i18n` 요소의 글을 바꾼다.
- 언어 결정 순서: 주소의 `?lang=` → 저장한 선택(localStorage) → 브라우저 언어(ko 로 시작하면 한국어, 아니면 영어).
- 영어 방문자에게 한국어가 비치지 않게, `index.html` 머리의 인라인 스크립트가 같은 규칙으로 `data-lang` 을 먼저 정하고 CSS 가 `i18n.js` 실행 전까지 본문을 숨긴다.
- 오른쪽 위 전환 버튼(EN / 한)을 누르면 주소의 `?lang=` 도 바뀌어 그대로 공유할 수 있다.
- 한국어 용어는 국립국어원 로마자 표기법으로 괄호에 함께 적는다(dalhangari, cheongja, baekja, buncheong, onggi).
- 본문을 채울 때는 확인한 한국어 사실을 영어로 옮긴다. 영어 문장도 같은 출처에 근거해야 한다.

## 실측(2026-11-19)

배포본(`vite build` → `vite preview` 4179)을 수상작과 같은 `~/.claude/scripts/design-trends/render/render_run.py` 로 쟀다. 결과 파일은 `docs/perf/`.

| 항목 | 값 |
|---|---|
| LCP | 88ms |
| CLS | 0.003 |
| 긴 작업 | 2건, 합계 150ms, 최대 85ms(1건은 스크롤 중) |
| 프레임 | 가만히 75.2fps, 스크롤 72fps(가장 긴 프레임 120ms) |
| 전송량 | 2,904KB |
| JS 메모리 | 17.2MB |

로컬 서버라 네트워크 지연이 빠졌다. LCP 는 실제 배포에서 더 길어진다. 긴 작업과 프레임은 같은 맥에서 잰 수상작 값과 비교할 수 있다. 서명 검색에 KTX2 가 잡힌 것은 GLTFLoader 안의 확장 이름 때문이고, 이 사이트는 KTX2 를 쓰지 않는다.

## 배포본 압축(2026-11-19)

- `vite.config.js` 에 `base: './'` 를 두고, 코드 안의 경로(`assets/*.glb`, `draco/`)는 `import.meta.env.BASE_URL` 로 붙인다. 그래서 하위 경로에 올려도 열린다. 빌드를 `/korean-ceramics/` 아래에 두고 띄워 정지 이미지 · 스크립트 · CSS · glb · Draco 디코더가 모두 200 으로 오는 것을 확인했다.
- `~/Downloads/korean-ceramics-site-20261119.zip`(22MB, 612개 파일): `dist/` 와 여는 방법을 적은 README.txt. 파일 수와 크기의 대부분은 글꼴 조각이고, 브라우저는 쓰는 글자의 조각만 받는다.
